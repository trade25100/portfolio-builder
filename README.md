# Portfolio Builder — Contact et Footer originaux

Cette version conserve les sections **START CONTACT SECTION** et **START FOOTER SECTION** telles que fournies, dans l’éditeur et dans le HTML exporté. Les liens Facebook et Twitter pointent toujours vers `#contact`, comme dans votre code.

Ouvrir `index.html`, ajouter ou modifier des projets, puis cliquer sur **Exporter HTML public** pour créer la page à publier sur GitHub Pages.

Les données de l’éditeur sont conservées localement ; exportez aussi le JSON pour les sauvegarder.
